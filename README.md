# lwDASH
A minimalist web dashboard based on pure javascript

## Features
- Smooth appearence, animation, dark theme, user friendly
- Multilingual template support (elements can change localization in real time)
- Interactive hint mode: in this mode you can provide additional info about element functionality to the user
- Simple websocket service that supports network messaging and notifies user of network problems
- Zero dependency. ALL widgets have zero dependency or depend on other widgets (which SHALL be specified explicitly in code)

## Usage:
- Run `make.sh demo/demo.js`, it compiles the demo example
- Output HTML files are in the `build` directory
